# StoryMood 공연 사용 스토리

실제 동화 구연 공연에서 StoryMood를 사용하는 시나리오입니다.
이 문서의 각 단계는 앱 기능 요구사항의 근거가 됩니다.

## 페르소나

**김수진 (38세, 동화구연가)**
- 유치원·도서관에서 월 6~8회 동화 구연 공연을 함
- 지금까지는 노트북 + 음향 담당 보조 1명이 효과음을 수동으로 틀어줌
- 보조 없이 혼자 공연하고 싶어서 StoryMood를 도입
- 기기: iPhone 15 Pro (공연용), 블루투스 스피커 연결

## 시나리오 1 — 공연 전날: 리허설

1. 수진은 집에서 앱을 열고 **이야기 모드** 탭에서 「빨간 모자」를 선택한다.
2. 큐시트를 훑어보며 각 문단의 **큐 키워드**(파란 굵은 글씨)와 연결된 효과음을 확인한다.
3. 몇몇 큐의 소리가 마음에 안 들어 ✏️ 버튼으로 **다른 효과음으로 교체**한다. (교체한 큐는 주황색 표시)
4. **이야기 시작**을 눌러 실제로 낭독하며 리허설한다.
   - "사냥꾼이" 를 말하면 1초 뒤(⏱1.0초) 총소리가 나는 타이밍을 확인
   - 인식이 어긋난 큐는 ▶️ 수동 재생 버튼 위치를 미리 손에 익혀둔다
5. 타이밍이 안 맞는 큐는 delay 값 튜닝 대상으로 메모한다.

## 시나리오 2 — 공연 당일: 세팅

1. 공연장 도착 후 iPhone을 블루투스 스피커에 연결한다.
2. **방해금지 모드**를 켠다. (전화가 와도 앱이 자동 복구하지만, 애초에 안 오는 게 최선)
3. 보면대(악보 거치대)에 iPhone을 **가로로 거치**한다.
   - 가로모드에서는 왼쪽에 시작/종료·재생 컨트롤, 오른쪽에 큐시트가 나란히 보인다
   - 가로 화면은 한 줄에 더 긴 문장이 들어가 낭독 중 시선 이동이 적다
4. **소리 모음** 탭에서 무드 BGM을 미리 골라두고 볼륨을 공연장에 맞게 조절한다.
5. 앱은 공연 중 **화면 자동 잠금이 걸리지 않으므로** 별도 설정이 필요 없다.

## 시나리오 3 — 공연 본편 (25분)

1. 아이들이 자리에 앉으면 **이야기 모드 → 빨간 모자 → 이야기 시작**을 누른다.
2. 마이크 인식이 시작되고(듣는 중… 표시), 수진은 평소처럼 구연을 시작한다.
3. **"깊은 숲속 오두막에 바람이…"** — "바람이"가 인식되면 0.5초 뒤 바람 소리가 자동 재생된다.
   - 현재 대기 중인 큐는 파란 테두리 + 👂 아이콘으로 표시되고, 큐시트가 자동 스크롤된다
4. 아이들이 소란스러워 한 큐가 인식되지 않았다 → 당황하지 않고 해당 문단의 **▶️ 수동 재생**을 누른다.
5. 효과음이 너무 길게 남으면 하단 재생 바의 **⏹ 정지**를 누른다. (0.15초 페이드아웃이라 뚝 끊기지 않음)
6. 클라이맥스에서 긴장감 BGM을 깔고 싶어 잠깐 **소리 모음 탭**으로 넘어가 무드 BGM을 켠 뒤 다시 돌아온다.
7. 이야기의 마지막 큐가 끝나면 "이야기 끝! ⭐" 표시를 확인하고 **이야기 종료**를 누른다.

## 시나리오 4 — 돌발 상황

| 상황 | 앱의 동작 | 수진의 대응 |
|---|---|---|
| 전화 수신 | 오디오 중단 후 통화 종료 시 자동 재개 | 거절 버튼만 누르고 계속 진행 |
| 큐 오인식(건너뜀) | 대기 큐가 다음으로 안 넘어감 | 해당 큐 ▶️ 수동 재생 |
| 소음으로 음성 인식 불안정 | 인식된 텍스트가 하단에 실시간 표시 | 수동 재생 위주로 전환 |
| 화면 방향이 바뀜 | 가로/세로 모두 동일 기능 제공 | 거치 각도만 다시 조정 |

## 요구사항 체크리스트

| 요구사항 | 상태 |
|---|---|
| 음성 인식 자동 큐 + 수동 재생 백업 | ✅ 구현됨 |
| 큐 조기 인식 + 지연(delay) 재생 | ✅ 구현됨 (리허설 튜닝 진행 중) |
| 화면 자동 잠금 방지 | ✅ 구현됨 |
| 오디오 인터럽션(전화) 자동 복구 | ✅ 구현됨 |
| 정지 시 페이드아웃 | ✅ 구현됨 |
| **가로모드 공연 레이아웃** (컨트롤 + 큐시트 2단) | ✅ 구현됨 (2026-07-13) |
| 큐별 delay 실측 튜닝 | ⏳ 리허설 필요 |
